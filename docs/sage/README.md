## Patches

### P1 - Add timeout=30 to requests calls that can block forever (SKIPPED, rule-based)

`requests` has no default timeout. A stalled socket hangs a test or CI job indefinitely - a classic source of flaky/slow CI. Each unbounded call now has an explicit 30s bound. Behaviour change: calls that legitimately take longer will now raise requests.Timeout.

### P3 - Enable pip dependency caching in GitHub Actions setup-python steps (SKIPPED, rule-based)

Without caching, every CI run re-downloads all dependencies. `cache: pip` keys the cache on requirements.txt. Verified statically (valid YAML, only additive change); GitHub Actions cannot be executed locally, so the first CI run on the PR is the real confirmation.

### P2 - Replace yaml.load(x) with yaml.safe_load(x) (SKIPPED, rule-based)

yaml.load without a Loader can construct arbitrary Python objects from untrusted input (code execution). safe_load is a drop-in for plain data documents.
